# Cisco Networking Labs

This repository contains my Cisco Packet Tracer networking labs created while learning Computer Networks and CCNA concepts.

## Labs

### Lab 1 - Point-to-Point (P2P)

* Basic point-to-point network configuration.
* IP addressing and connectivity testing.

### Lab 2 - LAN

* Local Area Network setup using switches and PCs.
* IP configuration and communication testing using ping.

### Lab 3 - Configure VLANs

* VLAN creation and assignment.
* Inter-device communication testing within VLANs.

## Tools Used

* Cisco Packet Tracer 9.0
* Git & GitHub

## Topics Covered

* IP Addressing
* Switching
* LAN Configuration
* VLAN Configuration
* Connectivity Testing
* Basic Network Troubleshooting
